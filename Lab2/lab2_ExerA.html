About the Event

The Faculty Programming Workshop is a one-day event designed to introduce students to programming, teamwork, and problem-solving.

Speaker 1: Dr. Ahmad

Dr. Ahmad will introduce programming fundamentals and explain how programming skills are used in real-world applications.

Activity: Hands-on Coding

Students will participate in a practical coding session and solve simple programming problems.
